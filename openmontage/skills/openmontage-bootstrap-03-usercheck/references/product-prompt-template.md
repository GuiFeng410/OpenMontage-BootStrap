# 商品宣传 / 展示类 · AI 视频提示词模板

| 项 | 内容 |
|----|------|
| 版本 | **v0.2** |
| 状态 | **已定稿（可迭代）**；随 `03-usercheck` 仓内分发 |
| 受众 | 出片 Agent / 商品试片执行者 |
| **权威落盘** | 本文件（Skill references）；跨机器以仓内此路径为准 |
| 人读副本 | `docs/A_Explain/03-商品宣传提示词模板.md`（可能未推远程） |
| 关联 | BootStrap `03-usercheck` 表 3 / `video_plan`（重度商品强制） |

**与主流程关系**：服从时长软约束与简报确认顺序；本文件是**商品生成片提示词与切段策略**，不修改已冻结 v1.0 业务规则，也不改 Agnes/eRouter 代码。

**明确不做（本版）**：改生成工具代码；另起独立 Skill；封成唯一品类「官方片」。

---

## 1. 目的

为**商品宣传 / 展示类** AI 生成视频（尤其 ≥30s 多段拼接）提供可复用骨架，从提示词侧提升稳定性与观感：

1. 先对上传图片做**素材分类**，默认**纯产品**；人物佩戴另闸；
2. 缺图 / 不够段时**先问用户**补齐（默认可图生图）；
3. 按时长选切段策略，并锁定**重点段**；
4. 再按叙事弧与镜头池填槽位；
5. **中文槽位**给人确认 → **英文**组装喂模型；
6. 分清固定项 / AI 裁量 / 用户与模板冲突时的裁决。

---

## 2. 使用顺序（第 0 步起）

```text
① 素材分类（§2.1）→ 路径选择（§2.2）→ 缺图则询问补齐（§2.3）
② 按时长选切段策略（可升级，须确认）
③ 锁定重点段（默认规则见 §3；可确认覆盖）
④ 套叙事弧 Hook → Hero → Detail → Close（段数缩放）
⑤ 填总片卡 + 分段卡（中文槽位，每段绑主参考图）→ 用户确认
⑥ 组装英文单镜 prompt → 生成（重点段优先迭代）
⑦ 硬约束冲突须「确认覆盖」并记入决策 / artifacts
```

与 BootStrap 对齐时：表 1 / 表 2 确认之后，填表 3（`video_plan`）前 **必须先读本文**（商品片含重度商品由 `03-usercheck` 强制）。

## 2.1 素材分类（商品片、出表 3 前必做）

对用户上传的**图片**先分类，出示简表请用户确认或改标：

| 标签 | 含义 | 典型用途 |
|------|------|----------|
| `product_hero` | 产品全貌 | 建立 / Hero |
| `product_detail` | 微距 / 材质 / logo | Detail |
| `product_angle` | 另一角度 | 拆段第二参考 |
| `on_body` / `hand` | 佩戴或手持 | **仅佩戴支** |
| `person_only` | 只有人、无清晰货 | **不作产品主参考** |
| `scene` / `other` | 场景或其它 | 环境或弃用 |

简表须含：各类张数、是否含人物、**相对目标时长/切段是否够参考图**。

---

## 2.2 路径选择（默认纯产品）

| 情况 | 路径 |
|------|------|
| 未要求人物 | **纯产品**（推荐） |
| 要求佩戴/上身且无合格 `on_body`/`hand` | **不直接烧视频** → §2.3 补参考或劝退 |
| 要求佩戴且有合格图 | **佩戴支** + §4.3 人物硬约束 |
| 仅有人像、无清晰产品 | 先补产品图，不开长片 |

---

## 2.3 缺图 / 不够段（须问用户；禁止静默补图）

触发任一即先停再问：

- 目标要 2×5s / 多段，但可用产品参考不足；
- 单图撑 10s 判定吃力，建议拆段但缺第二张；
- 要走佩戴却无合格佩戴图。

**询问话术（固定结构）：**

> 当前素材分类结果：…  
> 相对本单时长/切段，还缺：…（如「第 2 段参考图」）  
>
> 请选一种补齐方式：  
> 1. **我再上传素材**（放到项目 `assets/images/`）  
> 2. **图生图补图**（默认推荐：从已有产品图生成同锚点变体角度/微距）  
> 3. **不补图**：维持单段/降级方案（说明观感上限）  
>
> 直接回复「按默认」或「同意补图」→ **按方式 2 图生图**执行。  
> 回复「我自己传」→ 等上传后再分类、再出表 3。

| 用户口令 | 行为 |
|----------|------|
| 「按默认」/「同意」/「可以」/「用图生图」 | **默认图生图** |
| 「我再传」/「自己加素材」 | 等上传 → 重跑 §2.1 |
| 「不补」 | 降级（如 10s 保持 1 段、单主动作），记决策后继续 |

**禁止**未经询问自动 I2I、或把生成图静默冒充用户原图。

图生图约束：保持材质/主色/logo 策略；目标标签多为 `product_angle` / `product_detail`（确有需要才做局部佩戴特写）；禁止乱风格。补完再分类，路径写入 `video_plan`。

## 3. 时长策略与重点段

### 3.1 切段表

| 目标时长 | 默认切段 | 升级条件 | 叙事落点（示意） |
|----------|----------|----------|------------------|
| ≤5–6s | 1 段 | 一般不拆 | Hero + 少许 Detail |
| **约 10s** | **1 段** | 要细控或单图吃力 → 提案 **2×~5s**；缺第 2 张 → §2.3 | 1 段：Hook+Hero；2 段：建立 → Hero/微距 |
| 约 20–30s | **3×~10s** | 某段缺参考 → §2.3 | Hook+建立 / **Hero** / Detail+Close |
| ~45–60s+ | 4～6 段 | 同上 | 完整四拍 + Detail/场景变体 |

**10s 定稿**：默认不拆；升 2×5s 须确认；缺图先走 §2.3。  
**≤5s**：不建议再拆（拼接成本高于收益）。  
每段须绑定**主参考图**（用户原图或已确认的 I2I 补图）。

### 3.2 重点段（定稿）

| 场景 | 默认重点段 | 倾斜什么 |
|------|------------|----------|
| 30s 三截（及同类 3 段） | **第 2 段（Hero）** | 重试次数、提示词打磨、参考帧/一致性优先 |
| 10s 升为 2×5s | 通常 **第 2 段** | 同上 |
| 10s 单段 | 该唯一段即重点 | 动作减到 1 个，忌信息过载 |
| 用户改重点 | 须确认后锁定 | 例如「重点打微距」→ 重点改末段 |

支撑段（Hook / Detail+Close）：一次通过即可；失败可降要求，少重烧。

## 4. 叙事弧与人物支路

### 4.1 叙事弧（定稿）

**Hook → Hero → Detail → Close**

| 拍 | 目的 | 30s 三截落点（例） |
|----|------|-------------------|
| Hook | 第一眼欲望 / 场景冲击 | 多并入第 1 段前半 |
| Hero | 产品全貌或佩戴/使用成立 | **第 2 段（重点）** |
| Detail | 材质、工艺、微距、光影 | 多并入第 3 段前半 |
| Close | 卖点收束 / CTA 氛围 | 多并入第 3 段后半（可弱化硬字幕 CTA） |

段数变少时合并拍号，**不得**把多主动作塞进同一生成段。

### 4.2 人物（定稿）

| 支路 | 何时用 |
|------|--------|
| **纯产品**（默认） | 用户未点名佩戴/上身/使用演示；**尽量不要出现人物** |
| **佩戴 / 手部互动** | 用户明确要求，**且**有合格 `on_body`/`hand` 参考（见 §2.1 / §2.2） |

无合格佩戴参考时：**禁止**硬烧佩戴支；走 §2.3 或劝退。无参考图时慎开佩戴支，避免脸/肢体/比例崩。

### 4.3 人物佩戴硬约束（仅佩戴支 · 英文组装必含方向）

正向写入（少堆「不要」）：

- 单人；**局部优先**（耳部 / 手部特写优于全身大幅运动）
- 商品固定在正确佩戴位置，相对人体比例正确
- **单主动作**（如轻微转头、手轻触产品）；禁止复杂走位、多手互动
- 与参考图同一人、同一妆造、同一商品
- 手指/肢体自然完整或合理虚化；避免扭曲畸形

## 5. 总片卡（中文槽位）

出片前填齐并确认：

| 槽位 | 说明 | 谁定 |
|------|------|------|
| 品类 | 如耳饰、箱包、美妆 | 用户 / 简报 |
| 卖点 | ≤3 条，可排序 | 用户锁定；AI 可建议 |
| 调性 | 如轻奢、清冷、温暖种草 | 用户或 AI 提案后确认 |
| 一致性锚点 | 材质、主色、logo 策略、人物身份（若有） | **固定**（硬约束） |
| 目标时长 | 秒数 | 用户（表 1） |
| 切段策略 | 段数 × 约时长 | §3 默认 + 确认 |
| 重点段 | 第几段 | §3.2 默认 + 确认 |
| 人物支路 | 纯产品 / 佩戴 | §4.2 |
| 素材分类 | §2.1 简表 | Agent 提案 + 用户可改 |
| 缺图补齐 | `none` / `user_upload` / `i2i` | §2.3 |
| 自带素材 | 路径或「无」 | 用户 |

---

## 6. 分段卡（每段中文槽位）

| 槽位 | 说明 | 固定？ |
|------|------|--------|
| 段序 / 约时长 | 如 S2 · 10s | 策略锁定后固定 |
| 镜头目的 | 对应 Hook/Hero/Detail/Close 之一或合并 | 骨架固定，措辞 AI |
| 景别 | 从 §7.1 池选 | 池固定；选哪个 AI（遵守不连续重复） |
| 运镜 | 从 §7.2 池选 | 同上 |
| 主动作 | **仅 1 个** | **硬约束** |
| 细节闸门 | 勾选 §7.3 | 默认全开，可确认关闭个别项 |
| 本段强调卖点 | 从总片 ≤3 卖点中选 1 | AI 可排，用户可改 |
| 参考素材 | **主参考图路径（必填）**；标签如 product_hero | 用户原图或已确认 I2I |
| 英文 prompt | 组装结果（佩戴支含 §4.3） | AI 生成；用户可改 |

## 7. 镜头池与质量闸门

### 7.1 景别池（轮换，禁止连续两段完全相同）

- 建立：3/4 侧、平视、中全景  
- 欲望：微距材质、手部互动、肩部以上佩戴（佩戴支）  
- 产品：顶部 45°、底部轮廓光、台面静物  

### 7.2 运镜池（幅度中等；单段只选一种主运镜）

- 缓慢推近、轻微环绕、固定机位微动态、跟手部轻触  
- **慎用**：猛甩、大幅变形、多事件叠动作  

### 7.3 细节 / 质量闸门（默认写入每段）

- 主体清晰、边缘干净  
- 材质词具体（勿只写「好看」「高级」）  
- 光：柔和主光 + 可控高光；避免脏噪、一片过曝  
- Logo/刻字：可读 **或** 干脆不出现（二选一写死）  
- 人物（若有）：身份与妆造稳定；商品相对比例正确  

模型不支持 negative 时：用正向替代写进英文句（如 `clean seamless backdrop`），不要堆「不要 XX」。

## 8. 语言与 Prompt 组装

### 8.1 语言（定稿）

| 层 | 语言 |
|----|------|
| 给人看的槽位 / 表 3 | **中文** |
| 喂生成模型 | **英文**（由槽位组装） |

### 8.2 组装骨架（英文）

```text
[product + anchors], [shot purpose], [framing], [camera move],
[single primary action], [material + lighting], [quality locks],
[style/tone], -- keep identity consistent with reference if any
```

**固定前缀（例）**：品类 + 锚点材质/颜色。  
**固定后缀（例）**：`sharp focus on product, clean composition, controlled highlights, no clutter`。  
**中间**：景别 + 运镜 + 唯一主动作 + 本段卖点。

### 8.3 示例（示意，非唯一官方片）

**10s 单段（纯产品）**  
槽位：Hero 为主；景别中全景；运镜缓推；动作「水平微旋转展示」。  
英文要点：product hero, medium-wide, slow push-in, gentle turntable rotation, material locks…

**10s → 2×5s（升级）**  
S1：建立/台面；S2（重点）：微距材质。各段仍单主动作。

**30s 三截**  
S1 Hook+建立；**S2 Hero 重点**；S3 Detail+Close。迭代预算优先 S2。

## 9. 固定 / AI 裁量 / 冲突

### 9.1 固定（硬约束）

- 已确认的切段策略与重点段  
- 单段单主动作  
- 一致性锚点与质量闸门默认句  
- 叙事弧四拍的合并规则（不可无目的乱序硬塞）  
- 中文槽位确认前不烧付费镜头（服从简报闸门）  
- **缺图须先走 §2.3**；禁止静默 I2I / 静默拆段硬烧  
- **无合格佩戴参考时禁止佩戴支硬烧**  

### 9.2 AI 可决定

- 池内景别/运镜组合（遵守不重复）  
- 形容词与光影比喻（不越调性）  
- 段内强调哪一条卖点（在已锁列表内）  
- 英文具体措辞  
- 分类标签初标（须用户可改）  
- I2I 变体角度方案（须用户按 §2.3 同意后才执行） 

### 9.3 冲突裁决（定稿）

| 类型 | 处理 |
|------|------|
| 硬约束 vs 用户新要求 | **不可静默改**；说明风险 → 用户说「确认覆盖」→ 记决策后改 |
| 软偏好（更梦幻/更多手部） | 用户优先；仅在池与支路内调整 |
| 能力外（原生 4K、单镜 30s 不切等） | 标不可行或降级，不硬扛 |
| 中途改切段 / 改重点段 | 策略变更，须确认；已有 clip 默认保留 |

口令：「按模板」= 全默认；「改 XX」= 只动点名槽；「确认覆盖」= 允许碰硬约束。

## 10. 与项目体系的衔接（本版）

| 环节 | 怎么用本文 |
|------|------------|
| `03-usercheck` 表 1 | 主题、档位、时长；判定商品片 |
| 表 2 | 轻度表现方式 / 中度素材 / 重度渠模；商品重度锁渠模后仍用本文写 prompt |
| 表 3 / `video_plan` | 按总片卡+分段卡；须含分类、路径、缺图策略、每段 `ref_image` |
| `04-produce` | 缺口未关闭不烧对应段；有 `i2i` 则先补图再 I2V；重点段优先重试 |
| 并行编排 | 30s 三截等与现有习惯一致；重点段失败优先补 |

**`video_plan` 建议增记字段：**

| 字段 | 含义 |
|------|------|
| `asset_classes` | §2.1 分类简表 |
| `path` | `product_only` / `on_body` |
| `gap_fill` | `none` / `user_upload` / `i2i`（及生成路径列表） |
| 每段 `ref_image` | 主参考图路径 |
