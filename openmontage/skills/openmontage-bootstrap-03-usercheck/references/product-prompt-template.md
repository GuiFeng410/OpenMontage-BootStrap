---

## 1. 目的

为**商品宣传 / 展示类** AI 生成视频（尤其 ≥30s 多段拼接）提供可复用骨架，从提示词侧提升稳定性与观感：

1. 先按时长选切段策略，并锁定**重点段**；
2. 再按叙事弧与镜头池填槽位；
3. **中文槽位**给人确认 → **英文**组装喂模型；
4. 分清固定项 / AI 裁量 / 用户与模板冲突时的裁决。

---

## 2. 使用顺序（第 0 步起）

```text
① 按时长选切段策略（可升级，须确认）
② 锁定重点段（默认规则见 §3；可确认覆盖）
③ 套叙事弧 Hook → Hero → Detail → Close（段数缩放）
④ 填总片卡 + 分段卡（中文槽位）→ 用户确认
⑤ 组装英文单镜 prompt → 生成（重点段优先迭代）
⑥ 硬约束冲突须「确认覆盖」并记入决策 / artifacts
```

与 BootStrap 对齐时：表 A / 表②确认之后，填表③（或等价 `ai_plan`）前 **必须先读本文**（由 `03-usercheck` 强制）。

## 3. 时长策略与重点段

### 3.1 切段表

| 目标时长 | 默认切段 | 升级条件 | 叙事落点（示意） |
|----------|----------|----------|------------------|
| ≤5–6s | 1 段 | 一般不拆 | Hero + 少许 Detail |
| **约 10s** | **1 段** | 控制不够，或需要「全貌 + 微距」分治 → **2×~5s** | 1 段：Hook+Hero 合一；2 段：建立 → Hero/微距 |
| 约 20–30s | **3×~10s** | — | 三段映射：Hook+建立 / **Hero** / Detail+Close |
| ~45–60s+ | 4～6 段 | — | 完整四拍 + Detail/场景变体 |

**10s 定稿**：默认不拆；升 2×5s 必须与用户确认。  
**≤5s**：不建议再拆（拼接成本高于收益）。

### 3.2 重点段（定稿）

| 场景 | 默认重点段 | 倾斜什么 |
|------|------------|----------|
| 30s 三截（及同类 3 段） | **第 2 段（Hero）** | 重试次数、提示词打磨、参考帧/一致性优先 |
| 10s 升为 2×5s | 通常 **第 2 段** | 同上 |
| 10s 单段 | 该唯一段即重点 | 动作减到 1 个，忌信息过载 |
| 用户改重点 | 须确认后锁定 | 例如「重点打微距」→ 重点改末段 |

支撑段（Hook / Detail+Close）：一次通过即可；失败可降要求，少重烧。

---

## 4. 叙事弧与人物支路

### 4.1 叙事弧（定稿）

**Hook → Hero → Detail → Close**

| 拍 | 目的 | 30s 三截落点（例） |
|----|------|-------------------|
| Hook | 第一眼欲望 / 场景冲击 | 多并入第 1 段前半 |
| Hero | 产品全貌或佩戴/使用成立 | **第 2 段（重点）** |
| Detail | 材质、工艺、微距、光影 | 多并入第 3 段前半 |
| Close | 卖点收束 / CTA 氛围 | 多并入第 3 段后半（可弱化硬字幕 CTA） |

段数变少时合并拍号，**不得**把多主动作塞进同一生成段。

### 4.2 人物（定稿）

| 支路 | 何时用 |
|------|--------|
| **纯产品**（默认） | 用户未点名佩戴/上身/使用演示 |
| **佩戴 / 手部互动** | 用户明确要求，或简报勾选「佩戴支」且有可用参考图 |

无参考图时慎开佩戴支，避免脸/比例崩。

---

## 5. 总片卡（中文槽位）

出片前填齐并确认：

| 槽位 | 说明 | 谁定 |
|------|------|------|
| 品类 | 如耳饰、箱包、美妆 | 用户 / 简报 |
| 卖点 | ≤3 条，可排序 | 用户锁定；AI 可建议 |
| 调性 | 如轻奢、清冷、温暖种草 | 用户或 AI 提案后确认 |
| 一致性锚点 | 材质、主色、logo 策略、人物身份（若有） | **固定**（硬约束） |
| 目标时长 | 秒数 | 用户（表 A） |
| 切段策略 | 段数 × 约时长 | §3 默认 + 确认 |
| 重点段 | 第几段 | §3.2 默认 + 确认 |
| 人物支路 | 纯产品 / 佩戴 | §4.2 |
| 自带素材 | 路径或「无」 | 用户 |

## 6. 分段卡（每段中文槽位）

| 槽位 | 说明 | 固定？ |
|------|------|--------|
| 段序 / 约时长 | 如 S2 · 10s | 策略锁定后固定 |
| 镜头目的 | 对应 Hook/Hero/Detail/Close 之一或合并 | 骨架固定，措辞 AI |
| 景别 | 从 §7.1 池选 | 池固定；选哪个 AI（遵守不连续重复） |
| 运镜 | 从 §7.2 池选 | 同上 |
| 主动作 | **仅 1 个** | **硬约束** |
| 细节闸门 | 勾选 §7.3 | 默认全开，可确认关闭个别项 |
| 本段强调卖点 | 从总片 ≤3 卖点中选 1 | AI 可排，用户可改 |
| 参考素材 | 有则填路径 | 用户 |
| 英文 prompt | 组装结果 | AI 生成；用户可改 |

## 7. 镜头池与质量闸门

### 7.1 景别池（轮换，禁止连续两段完全相同）

- 建立：3/4 侧、平视、中全景  
- 欲望：微距材质、手部互动、肩部以上佩戴（佩戴支）  
- 产品：顶部 45°、底部轮廓光、台面静物  

### 7.2 运镜池（幅度中等；单段只选一种主运镜）

- 缓慢推近、轻微环绕、固定机位微动态、跟手部轻触  
- **慎用**：猛甩、大幅变形、多事件叠动作  

### 7.3 细节 / 质量闸门（默认写入每段）

- 主体清晰、边缘干净  
- 材质词具体（勿只写「好看」「高级」）  
- 光：柔和主光 + 可控高光；避免脏噪、一片过曝  
- Logo/刻字：可读 **或** 干脆不出现（二选一写死）  
- 人物（若有）：身份与妆造稳定；商品相对比例正确  

模型不支持 negative 时：用正向替代写进英文句（如 `clean seamless backdrop`），不要堆「不要 XX」。

## 8. 语言与 Prompt 组装

### 8.1 语言（定稿）

| 层 | 语言 |
|----|------|
| 给人看的槽位 / 表③ | **中文** |
| 喂生成模型 | **英文**（由槽位组装） |

### 8.2 组装骨架（英文）

```text
[product + anchors], [shot purpose], [framing], [camera move],
[single primary action], [material + lighting], [quality locks],
[style/tone], -- keep identity consistent with reference if any
```

**固定前缀（例）**：品类 + 锚点材质/颜色。  
**固定后缀（例）**：`sharp focus on product, clean composition, controlled highlights, no clutter`。  
**中间**：景别 + 运镜 + 唯一主动作 + 本段卖点。

### 8.3 示例（示意，非唯一官方片）

**10s 单段（纯产品）**  
槽位：Hero 为主；景别中全景；运镜缓推；动作「水平微旋转展示」。  
英文要点：product hero, medium-wide, slow push-in, gentle turntable rotation, material locks…

**10s → 2×5s（升级）**  
S1：建立/台面；S2（重点）：微距材质。各段仍单主动作。

**30s 三截**  
S1 Hook+建立；**S2 Hero 重点**；S3 Detail+Close。迭代预算优先 S2。

## 9. 固定 / AI 裁量 / 冲突

### 9.1 固定（硬约束）

- 已确认的切段策略与重点段  
- 单段单主动作  
- 一致性锚点与质量闸门默认句  
- 叙事弧四拍的合并规则（不可无目的乱序硬塞）  
- 中文槽位确认前不烧付费镜头（服从简报闸门）  

### 9.2 AI 可决定

- 池内景别/运镜组合（遵守不重复）  
- 形容词与光影比喻（不越调性）  
- 段内强调哪一条卖点（在已锁列表内）  
- 英文具体措辞  

### 9.3 冲突裁决（定稿）

| 类型 | 处理 |
|------|------|
| 硬约束 vs 用户新要求 | **不可静默改**；说明风险 → 用户说「确认覆盖」→ 记决策后改 |
| 软偏好（更梦幻/更多手部） | 用户优先；仅在池与支路内调整 |
| 能力外（原生 4K、单镜 30s 不切等） | 标不可行或降级，不硬扛 |
| 中途改切段 / 改重点段 | 策略变更，须确认；已有 clip 默认保留 |

口令：「按模板」= 全默认；「改 XX」= 只动点名槽；「确认覆盖」= 允许碰硬约束。

## 10. 与项目体系的衔接（本版）

| 环节 | 怎么用本文 |
|------|------------|
| `03-usercheck` 表 A | 时长、是否 AI 视频、素材；判定商品片后表③必读本文 |
| 表 ② | 渠道/模型锁定后，生成侧仍用本文写 prompt |
| 表 ③ / `ai_plan` | **按**总片卡+分段卡填写（商品片专用写法） |
| `04-produce` | 按锁定的段数与重点段编排并行/串行与重试倾斜 |
| 并行编排 | 30s 三截等与现有 `parallel_generate` 习惯一致；重点段失败优先补 |
