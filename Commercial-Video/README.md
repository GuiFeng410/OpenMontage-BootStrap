# Commercial-Video

商品宣传视频的独立工作区。

每个商品视频使用一个独立项目目录：

```text
Commercial-Video/
└── <product-project>/
```

时长 ≥15 秒的商品视频，审查扩展见  
`openmontage/skills/openmontage-bootstrap-03-usercheck/references/commercial-video-15s-review.md`。  
专业模式大致按：

```text
总览表 -> 分批审查卡 -> 修改清单确认 -> 分批锁定 -> 整片合成
```

普通模式默认：方案 → 试片 → 初稿/问题片段 → 终稿（不强制逐 beat 分批）。

现有 pipeline 运行目录仍由项目 Manifest 记录。不要为了整理目录而移动已经生成的素材。
