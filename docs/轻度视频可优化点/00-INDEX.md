# 00-INDEX

本目录存放"轻度视频可优化点"的清单，后续持续补充未深入处理的方向。
每条以一个小文件记录，统一命名：`NN-标题.md`。

## 条目

- [01-分镜节奏感弱](01-分镜节奏感弱.md) — `generate_scene_plan` 未强制"3-5s/段"，Remotion 侧也未做节奏分析
- [02-缺少多候选比较](02-缺少多候选比较.md) — scene_plan 只存一个结果，没有"同一镜头 N 个候选对比"
- [03-HyperFrames 集成不完整](03-HyperFrames 集成不完整.md) — 已写 bridge，但还没把 HyperFrames 作为一等公民接入
- [04-Remotion 渲染缺少重试/降级](04-Remotion 渲染缺少重试/降级.md) — 渲染失败时只有单次尝试
- [05-缺少渲染质量门禁](05-缺少渲染质量门禁.md) — 没有"成片 before 交付"的自动化检查
- [06-本地模型质量不稳定](06-本地模型质量不稳定.md) — WAN / Hunyuan / ComfyUI 等本地视频模型质量参差不齐
- [07-商品一致性提示词未自动化](07-商品一致性提示词未自动化.md) — 已有 docs 规范，但 pipeline 未强制注入
- [08-音频/配乐未与画面节奏对齐](08-音频配乐未与画面节奏对齐.md) — beat 之间有音频但没有 beat-sync
- [09-字幕时机未与画面事件对齐](09-字幕时机未与画面事件对齐.md) — caption 是固定 offset，未做事件对齐
- [10-素材多样性检查缺失](10-素材多样性检查缺失.md) — 没有检查"同一镜头是否用了太相似的素材"
- [11-多语言本地化成本未优化](11-多语言本地化成本未优化.md) — localization-dub 每语言重新生成所有视频
- [12-A/B 测试框架缺失](12-AB 测试框架缺失.md) — 没有并行生成多个版本做对比的能力
- [13-渲染产物缺少版本管理](13-渲染产物缺少版本管理.md) — renders 目录没有清晰的版本记录
- [14-成本追踪只到工具级](14-成本追踪只到工具级.md) — 没有"单镜头成本"和"单项目成本"的汇总
